# Design and Analysis of Algorithms (DAA) Practicals

This repository contains the practical programs implemented in **C++** as part of the Design and Analysis of Algorithms (DAA) course during my semester.

## About the Repository

The purpose of this repository is to implement and understand fundamental algorithms, analyze their time complexity, and develop problem-solving skills through practical programming.

## Practicals Included

### Practical 1: Sorting Algorithms
Implementation of the following sorting algorithms:
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Practical 2: Searching Algorithms
Implementation and time analysis of:
- Linear Search
- Binary Search

### Practical 3: Max-Heap Sort
Implementation of the Max-Heap Sort algorithm.

### Practical 4: Factorial Using Iteration and Recursion
Implementation and time analysis of a factorial program using iterative and recursive methods.

### Practical 5: Knapsack Problem
Implementation of the Knapsack Problem using Dynamic Programming.

### Practical 6: Chain Matrix Multiplication
Implementation of Chain Matrix Multiplication using Dynamic Programming.

### Practical 7: Making Change Problem
Implementation of the Making Change Problem using Dynamic Programming.

### Practical 8: Graph Traversal Algorithms
Implementation of graphs and graph traversal algorithms:
- Depth-First Search (DFS)
- Breadth-First Search (BFS)

### Practical 9: Prim's Algorithm
Implementation of Prim's algorithm for finding a Minimum Spanning Tree (MST).

### Practical 10: Kruskal's Algorithm
Implementation of Kruskal's algorithm for finding a Minimum Spanning Tree (MST).

### Practical 11: Floyd–Warshall Algorithm
Implementation of the Floyd–Warshall algorithm for finding shortest paths between all pairs of vertices in a graph.

### Practical 12: Travelling Salesman Problem (TSP)
Implementation of the Travelling Salesman Problem.

## How to Run the Programs

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required `.cpp` file.
4. Compile and execute the program using a C++ compiler.

### Compile and Run Using g++

```bash
g++ filename.cpp -o output
./output
```

Replace `filename.cpp` with the name of the C++ program you want to execute.

**Note:** On Windows, run the compiled program using `output.exe` instead of `./output`.
